한글 패치

적용 전 확인

The Midnight Ride 설치를 마쳤다면 TMR 비공식 한국어 패쳐로 본편·DLC와 지원되는 TMR 모드에 한국어 번역을 적용할 수 있습니다. Wabbajack 설치와 수동 설치 모두 같은 방법으로 진행합니다.

이 패쳐는 한국어 가이드와 함께 제공하는 별도 도구이며, ModdingLinked 또는 The Midnight Ride 제작진의 공식 도구가 아닙니다. Fallout 4 영문판 기반의 TMR 환경을 대상으로 합니다.

  1. Wabbajack 설치 및 설정 또는 수동 가이드의 설치 과정을 먼저 마칩니다.
  2. MO2에서 플레이할 프로필을 선택합니다. 패쳐는 현재 선택한 프로필의 활성 모드를 기준으로 번역 파일을 만듭니다.
  3. 게임과 MO2를 종료합니다.

1. 패쳐 다운로드

  1. 최신 한글 패쳐 다운로드 페이지를 엽니다.
  2. Assets에서 TMR-Korean-Patcher-v버전.zip을 받습니다. 현재 안내 기준은 v1.0.4입니다. Source code는 실행용 패키지가 아닙니다.
  3. ZIP 전체를 별도 폴더에 압축 해제합니다. TMR-Korean-Patcher.exe, TranslationData, FO4_AE_1.11.191.Kor를 함께 유지하세요. 본편 한국어 리소스는 이미 포함되어 있습니다.

2. Output 생성

  1. TMR-Korean-Patcher.exe를 실행합니다.
  2. 찾아보기로 ModOrganizer.ini가 있는 TMR MO2 루트 폴더를 선택합니다. 예: C:\Modlists\TMR
  3. Output 생성을 누르고 완료될 때까지 기다립니다.
  4. Output 폴더 열기로 방금 생성된 결과를 엽니다. 기존 Output이 있으면 Output-날짜-시간 이름으로 새 결과가 생성됩니다.

이 단계에서는 설치된 모드를 직접 수정하지 않습니다. 오류가 발생하면 적용을 멈추고 표시된 내용을 확인하세요. 게임의 Data나 MO2의 mods 폴더를 입력 경로로 선택하면 안 됩니다.

번역 적용 및 실행

3. 결과를 TMR에 복사

  1. 방금 생성한 Output 안의 mods 폴더를 TMR MO2 루트에 복사합니다. overwrite 폴더도 생성됐다면 함께 복사합니다.
  2. 같은 이름의 폴더는 병합하고, 같은 이름의 파일은 덮어쓰기를 허용합니다.

예를 들어 출력 파일이 Output\mods\모드명\파일이라면, 복사 후 경로는 C:\Modlists\TMR\mods\모드명\파일이 됩니다. Output 폴더 자체를 복사하거나 게임 Data 폴더에 넣지 마세요.

본편 번역은 새 모드 FO4 KOREAN으로 추가되고, TMR 모드 번역은 기존 각 모드 폴더의 파일을 덮어씁니다. 패쳐 ZIP을 MO2에 모드로 설치하는 방식은 아닙니다.

4. MO2에서 활성화

  1. MO2를 열고 적용할 프로필에서 왼쪽 모드 목록의 FO4 KOREAN을 체크합니다.
  2. 우선순위 오름차순 정렬 기준으로 FO4 KOREAN을 목록 맨 아래에 배치하여 한국어 리소스가 다른 모드보다 우선하도록 합니다.
  3. MO2를 통해 F4SE로 게임을 실행하고 메뉴·자막·MCM의 한국어 표시를 확인합니다.

별도의 TMR KOREAN 모드는 생성되지 않습니다. 번역 적용만을 위해 오른쪽 플러그인 목록의 로드 순서를 바꿀 필요는 없습니다. 다른 프로필을 사용하려면 해당 프로필 기준으로도 패쳐를 실행하고 FO4 KOREAN을 활성화하세요.

업데이트와 참고사항

TMR 업데이트 후 재적용

Wabbajack으로 목록을 업데이트하거나 모드를 다시 설치하면 번역한 파일이 영문 원본으로 교체될 수 있습니다. TMR 업데이트를 마친 뒤 최신 패쳐로 Output을 다시 생성하고 위 순서대로 복사·활성화하세요. 예전 Output을 새 버전 모드에 그대로 덮어쓰지 마세요.

과거 패치로 문자열 자체가 ???로 저장된 파일은 폰트를 바꿔도 복구되지 않습니다. 문제가 있는 모드의 공식 원본을 복원한 다음 최신 패쳐를 적용하세요. 사용자 프로필·설정·세이브를 삭제할 필요는 없습니다.

알려진 제한과 문의

  • 현 내장 폰트에는 겍·됬 등 일부 한글 음절이 없어 글자가 빠질 수 있습니다.
  • 과거 문제 제보에 대한 예방 조치로 지몬자 관련 일부 장소명은 영문을 유지합니다.
  • 외부 문자열 테이블을 쓰는 localized 플러그인은 현재 번역 대상에서 제외되며 경고에 표시될 수 있습니다.
  • v1.0.4는 사용자 플레이에서 한국어 표시와 확인한 구간의 지형이 정상으로 보고됐습니다. 모든 지역과 장시간 플레이의 안정성을 보증하는 것은 아닙니다.

버전별 변경사항과 상세 제한은 릴리즈 노트에서 확인하세요. 번역 오류나 적용 문제는 한글 패쳐 이슈에 패쳐 버전, TMR 프로필, 오류 내용과 함께 알려주세요.
