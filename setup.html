VC++ 재배포 패키지 설치

대부분의 엔진 모드와 도구는 최신 Visual C++ Redistributables가 필요합니다. Windows 공식 패키지 관리자인 Winget을 사용하면 필요한 패키지를 빠르고 안전하게 업데이트할 수 있습니다. 스크립트가 정상 작동하도록 먼저 Microsoft Store를 통해 Winget을 최신 상태로 맞춥니다.

최신 버전이 설치되어 있지 않으면 게임이나 모딩 도구를 실행하자마자 충돌할 수 있습니다.

이미 설치되어 있더라도 오래된 버전일 수 있으니 재배포 패키지를 다시 설치해 주세요.

  1. Microsoft Store를 엽니다.
  2. Updates & downloads로 이동합니다.
  3. Check for updates를 눌러 모든 항목을 업데이트합니다.
  4. 완료되면 Command Prompt를 열고 아래 명령을 입력합니다:
  5. PC를 재시작합니다.

파일 확장자 표시

시작하기 전에 Windows에서 파일 확장자가 보이도록 설정합니다.

기본 설정에서는 File Explorer가 .exe, .dll, .esp 같은 확장자를 표시하지 않습니다. 가이드에서 파일 종류를 구분하는 데 매우 중요하므로 확장자 표시를 켜는 것을 강력히 권장합니다:

  1. File Explorer를 엽니다.
  2. 상단의 View 탭을 선택합니다.
  3. Show 항목에서 File name extensions를 켭니다.

게임 설치

설치 위치 선택

클린 설치는 이전 모드 파일을 완전히 제거하기 위해서뿐 아니라 게임을 안전한 위치에 설치하기 위해서도 필요합니다. 설치 위치를 정할 때 다음 내용을 확인하세요:

  • Windows 기본 폴더는 피합니다: C:\Program Files, C:\Program Files x86, Desktop, Documents 등이 해당합니다.
    Program Files는 쓰기 권한 제약이 있고, Desktop과 Documents는 OneDrive가 관리하는 경우가 많아 게임과 모딩 도구에 문제를 일으킬 수 있습니다.

    안전한 위치의 예: C:\Games
  • 가능하면 SSD에 설치합니다: 로딩 시간이 크게 줄고 끊김 현상도 완화됩니다.

기존 게임 제거

Fallout 4를 한 번도 설치한 적이 없다면 다음 항목으로 넘어가세요.

이미 게임을 제거했다면 남은 파일이 없도록 4번과 5번 단계는 반드시 확인하세요.

  1. Steam을 열고 Library로 이동합니다.
  2. 목록에서 Fallout 4를 찾습니다.
  3. 우클릭한 뒤 Manage → Uninstall을 선택합니다.
  4. Steam\steamapps\common으로 이동해 Fallout 4 폴더가 남아 있다면 삭제합니다.
  5. Documents\My Games\Fallout 4로 이동해 안에 있는 INI 파일을 모두 삭제합니다.

새 Steam 라이브러리 만들기

엄격한 파일 보호 때문에 일부 모드와 도구가 오작동할 수 있으므로 Program Files (x86) 같은 Windows 기본 폴더 밖에 게임을 설치하는 것을 강력히 권장합니다. Steam Library Setup Tool을 사용해 기본 폴더 밖에 새 Steam 라이브러리를 만듭니다.

Steam 자체가 이미 Windows 기본 폴더 밖에 설치되어 있다면 다음 항목의 1번 단계로 넘어가 기존 사용자 지정 Steam 라이브러리에 게임을 설치하세요.

  1. Task Manager 또는 System Tray에서 Steam을 완전히 종료합니다.
  2. steam_library_setup_tool-3.2.exe를 다운로드합니다.
  3. 다운로드한 파일을 실행하고 Add Row를 눌러 새 항목을 추가합니다.
  4. Path에 원하는 경로를 입력합니다. 예: C:\Games\Steam
  5. Accept를 누르고 새 폴더 생성 여부를 묻는 창이 나오면 Yes를 선택합니다.
  6. 도구가 종료 여부를 물으면 OK를 선택합니다.

게임 설치

  1. Steam을 열고 Library로 이동합니다.
  2. 목록에서 Fallout 4를 찾아 Install을 선택합니다.
  3. Install to:에서 방금 만든 라이브러리 폴더를 선택합니다. 시스템 드라이브에 설치했다면 두 번째 C:\ 항목입니다.
  4. Next를 누르고 설치가 끝날 때까지 기다립니다.

새 라이브러리가 보이지 않으면 PC를 재시작합니다.

설치 후 설정

주요 용어

게임 설치를 마쳤습니다. 이후 가이드에서 자주 언급하는 폴더는 다음 두 곳입니다:

  • Root(게임 루트) 폴더: 게임이 설치된 폴더입니다.

    • Steam\steamapps\common\Fallout 4

  • Data 폴더: 게임의 에셋이 들어 있는 폴더입니다.

    • Steam\steamapps\common\Fallout 4\Data

새 INI 파일 생성

  1. Steam에서 게임을 실행합니다.
  2. Detecting Video Hardware라는 팝업 두 개에서 모두 OK를 누릅니다.
    • 팝업이 나오지 않으면 Documents\My Games\Fallout 4의 INI 파일을 모두 삭제한 뒤 다시 시도합니다.
  3. OK를 누른 뒤 Exit로 종료합니다.

High DPI 스케일링 설정

  1. Root 폴더의 Fallout4.exe를 우클릭합니다.
  2. Properties를 열고 Compatibility 탭으로 이동합니다.
  3. Change high DPI settings를 클릭합니다.
  4. High DPI scaling override를 Application으로 설정합니다.
