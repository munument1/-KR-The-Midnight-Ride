Wabbajack

Wabbajack이란?

Wabbajack은 자동 모드리스트 설치 프로그램입니다. The Midnight Ride Extended 전체 구성과 개선된 LOD 같은 추가 요소를 비교적 간단하게 설치할 수 있습니다.

사전 준비

먼저 소개를 읽고 초기 설정 페이지까지 진행하세요. Setup을 마치면 이 페이지로 돌아와 계속 진행합니다.

GOG 사용자는 TMR을 수동으로 설치해야 합니다. 현재 GOG판은 Wabbajack 목록에서 지원하지 않습니다.

GOG판의 데이터 파일이 오래된 상태라 UFO4P와 CFM 같은 수정 모드도 구버전을 사용해야 하기 때문입니다.

설치

  1. 최신 Wabbajack을 다운로드합니다.
  2. Windows 기본 폴더와 게임 폴더 밖에 새 폴더를 만듭니다.
    예: C:\Modding\Wabbajack
  3. 다운로드한 Wabbajack.exe를 이 폴더에 넣고 실행합니다.
  4. Browse lists를 클릭한 뒤 왼쪽에서 Non-featured를 체크합니다.
  5. The Midnight Ride를 찾아 Download & Install을 선택합니다.
  6. Installation Location에는 아래 위치가 아닌 빈 폴더를 지정합니다:
    • Steam 폴더
    • Windows 기본 폴더
    • 게임 폴더
    • Wabbajack.exe를 넣어 둔 폴더
    예: C:\Modding\The Midnight Ride
  7. Install을 누릅니다.
  8. Nexus Mods API 요청을 승인합니다.

Nexus Mods Premium 사용자가 아니라면 각 모드마다 다운로드 버튼을 직접 눌러야 합니다.

  1. 설치가 완료되면 초록색 Installation Complete 화면이 표시됩니다.
    • 빨간색 Installation failed 화면이 나오면 Wabbajack 설정에서 다시 로그인한 뒤 같은 폴더에 목록을 다시 설치해 보세요. 그래도 해결되지 않으면 원작 ModdingLinked Discord에서 지원을 받을 수 있습니다.

설치 후 단계

백신 예외 설정

MO2의 가상 파일 시스템 작동 방식 때문에 Windows가 MO2나 모드 파일의 로드를 차단할 수 있어 이 예외 설정이 필요합니다. 수동 설치에서는 MO2 설치 프로그램이 예외 처리를 담당하지만, Wabbajack 설치는 해당 설치 프로그램을 거치지 않으므로 직접 설정합니다.
  1. Windows Security를 엽니다.
  2. Virus & threat protection을 엽니다.
  3. Virus & threat protection settings 아래의 Manage settings를 클릭합니다.
  4. Exclusions까지 내려가 Add or remove exclusions를 클릭합니다.
  5. Folder 예외를 추가하고 Wabbajack의 Installation Location 폴더를 지정합니다.

타사 백신을 사용한다면 해당 백신의 예외 설정에서 같은 폴더를 예외로 추가합니다.

Root Mods (게임 루트 모드)

  1. Wabbajack 화면에서 Open in File Explorer를 클릭합니다.
  2. Files Requiring Manual Install 폴더를 엽니다.
  3. 모든 파일을 게임의 Root 폴더로 복사합니다.

Mod Organizer 2 설정

  1. Installation Location에서 ModOrganizer.exe를 실행합니다.
  2. Register? 팝업이 나오면 Yes를 선택합니다.

게임 설정

  1. MO2에서 Fallout Launcher를 선택해 게임 런처를 실행합니다.
  2. 런처에서 Options를 클릭하고 다음을 설정합니다:
    1. Ultra Preset을 선택합니다.
  3. 런처를 닫습니다.
  4. MO2의 Executables 메뉴에서 Bethini Pie를 선택합니다.
  5. Fallout 4를 클릭한 뒤 Select Game을 누릅니다.
  6. Setup 창이 뜨면 OK를 누릅니다. MO2의 VFS가 리디렉션을 처리하므로 INI 경로를 MO2 프로필 폴더로 바꿀 필요가 없습니다.
  7. 다음 설정을 적용합니다:
    1. 하드웨어에 맞는 Bethini preset을 선택합니다. 대부분의 시스템에는 High preset을 권장합니다.
    2. Recommended Tweaks를 적용합니다.
    3. Display Mode를 Borderless Windowed로 설정합니다.
    4. 게임에서 사용할 resolution을 선택합니다.
    5. Bethini Pie와 Steam 모두에서 Text Language가 English로 설정되어 있는지 확인합니다. 원본 가이드는 다른 게임 언어를 지원하지 않습니다.
    6. 나머지 설정은 취향에 맞게 조정합니다.
    7. 왼쪽 위의 File → Save를 누른 뒤 확인 창을 처리하고 Bethini를 종료합니다.

High FPS Physics Fix 설정

  1. Utilities 구분선에서 High FPS Physics Fix를 찾아 더블클릭합니다.
  2. INI Files 탭에서 F4SE/Plugins/HighFPSPhysicsFix.ini를 엽니다.
  3. 수동 가이드의 설정 단계를 적용한 뒤 이 페이지로 돌아옵니다.

게임 실행

The Midnight Ride를 Extended 구간 없이 플레이하려면 지금 MO2 모드 목록 위쪽 드롭다운에서 프로필을 전환합니다.

Mod Organizer 2의 작동 방식상 모드를 불러오려면 프로그램을 MO2를 통해 실행해야 합니다. 오른쪽 위 실행 프로그램 선택 메뉴에서 F4SE를 선택합니다.

F4SE가 보이지 않는다면 Root Mods 단계를 올바르게 적용하지 않은 것입니다.


편의를 위해 Run 버튼 바로 아래에서 바로가기를 만들어두면 게임을 할 때마다 MO2를 직접 열 필요가 없습니다.

MCM 설정

게임에 들어간 뒤 Mod Configuration 메뉴에서 각 모드 설정을 취향에 맞게 조정합니다.

이제 The Midnight Ride Wabbajack 목록 설치를 마쳤습니다. 더 이상 모드를 추가하지 않을 예정이라면 게임을 시작해도 됩니다.

마무리 안내

가이드 밖의 모드를 직접 추가하려면 게임의 기본적인 기술 구조부터 xEdit과 The Method를 이용한 충돌 해결까지 필요한 지식과 작업 흐름을 먼저 익히는 것을 권장합니다.

관련 자료는 자료 페이지에서 확인할 수 있습니다. 또한 피해야 할 도구와 피해야 할 모드 항목도 확인하세요.

가이드 밖의 모드를 추가한 구성은 원작 지원 대상에서 제외될 수 있습니다. 특히 많은 모드를 무리하게 추가한 경우에는 지원을 기대하기 어렵습니다.

모드리스트 업데이트

목록 업데이트

새 버전의 목록이 나오면 Wabbajack을 다시 실행하고 현재 목록이 설치된 동일한 폴더를 지정하면 됩니다.

  1. 기존 캐릭터를 계속 사용할 예정이라면 업데이트에 Safe Mid-Game 표시가 있는지 반드시 확인합니다.
  2. 설치 후 직접 추가한 모드가 있다면 왼쪽 패널의 이름 앞에 [NoDelete]를 붙입니다. 업데이트 후 위치가 바뀌거나 비활성화될 수 있습니다.
