KR 변경사항

2026-10-05

  • The Midnight Ride 비공식 한국어 번역 작업을 시작했습니다.
  • 모든 서비스 페이지에 noindex, nofollow, noarchive를 적용했습니다.
  • 공통 메뉴에 원본 가이드, 한국어 변경사항, 원작자 후원 안내를 추가했습니다.
  • 모바일 제목을 TMR 한국어로 표시하는 한국어 전용 규칙을 추가했습니다.
  • 첫 설치 구간(홈, 소개, 초기 설정, Mod Organizer 2)을 한국어로 번역했습니다.
  • 원본에 있던 잘못된 로컬 링크 3개를 수정했습니다.
  • Utilities, Bug Fixes, Base Finish 기본 설치 구간을 한국어로 번역했습니다.
  • FAQ/Utilities의 UTF-8 인코딩 손상을 복구하고 재발하지 않도록 Python 기반 수정으로 전환했습니다.
  • Base Finish의 loadorder.txt 다운로드를 한국어 저장소 내부 파일로 연결했습니다.
  • TMR Extended 6개 페이지(User Interface, Tweaks, Gameplay, Content, Visuals, Finish)를 한국어로 번역했습니다.
  • Resources, Light Plugins, Wabbajack 보조 페이지를 한국어로 번역했습니다.
  • Mods/Tools to Avoid 리다이렉트를 한국어판의 Safe Modding 페이지로 수정했습니다.
  • Safe Modding 페이지 전체를 한국어로 번역했습니다.
  • LOD 생성 가이드(FO4LODGen, TexGen, xLODGen)를 한국어로 번역했습니다.
  • FAQ 전체를 한국어로 번역하고 Load Order 안내를 한국어판 내부 페이지로 연결했습니다.
  • 최종 QA에서 누락된 콘텐츠 링크와 VRR 참고 앵커를 복원하고 모바일 헤더 간격을 조정했습니다.
  • 소개 페이지에서 하단 '가이드' 중복 링크 때문에 다음 화살표가 #로 남던 문제를 수정했습니다.
  • 원본 responsiveTitle 스크립트와 한국어 전용 스크립트가 동시에 제목을 수정하던 중복 로드를 제거하고 모바일 헤더 폭 처리를 보강했습니다.
  • 전체 가이드를 원본과 대조해 남아 있던 영어 설명문, FOMOD 안내, GPU/압축 도구 요구 사항, LOD 보충 문구와 오른쪽 목차의 일반 제목을 추가 한국어화했습니다.

원본 The Midnight Ride의 전체 변경 이력은 원본 Changelog에서 확인할 수 있습니다.
