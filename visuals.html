Upscaling

Upscaling is a technology aimed at improving the flexibility of a game's performance and visuals.

The internal resolution of your game is expressed as a preset that ranges from Native to Ultra Performance. Each preset progressively lowers the internal resolution that is fed to the upscaler. The upscaler then uses machine learning to reconstruct it back to the game's resolution. Native mode is the exception, improving the image without lowering internal resolution.

For example, running a 4K game in Performance mode renders it at 1080p before upscaling it back to 4K for display.

Upscaling requires a DX11.1 compatible GPU, you can check if yours is compatible by looking it up here, then refer to the Graphics Features list.


All 3 of the main GPU vendors have their own implementation of this same idea:

  • DLSS from Nvidia - the most advanced one, but locked to RTX GPUs.
  • FSR from AMD, GPU agnostic up until its latest iteration, FSR 4 (RDNA 3 and RDNA 4 only).
  • XeSS from Intel - GPU agnostic, although it favours Intel's Arc GPUs and is not as widely supported.

Input your game resolution below and hit Apply. The table's color coding will indicate how viable the various presets of a given upscaler are. Green would indicate that the upscaler has enough pixels to reconstruct a stable and accurate image. Orange and red entries should be considered only if performance is paramount - DLSS 4 in particular can get away with those lower sources if you don't pixel peep.

In numerous games, including Skyrim and Fallout 4 with the respective upscaling integration, upscaling has become a no-brainer. Compared to these games' traditional AA options (mostly TAA), upscaling massively improves visual clarity, fine detail resolve, sharpness, and performance (if not running in native mode).
