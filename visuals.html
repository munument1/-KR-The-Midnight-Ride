업스케일링

업스케일링은 게임의 성능과 화질 사이에서 더 유연하게 선택할 수 있도록 하는 기술입니다.

게임의 내부 렌더링 해상도는 Native부터 Ultra Performance까지의 preset으로 표현됩니다. 성능 위주의 preset일수록 업스케일러에 입력되는 내부 해상도가 낮아지고, 업스케일러가 머신러닝을 사용해 최종 게임 해상도로 복원합니다. Native 모드는 예외로 내부 해상도를 낮추지 않고 이미지 품질만 개선합니다.

예를 들어 4K에서 Performance 모드를 사용하면 내부적으로 1080p로 렌더링한 뒤 다시 4K로 업스케일해 화면에 표시합니다.

업스케일링에는 DX11.1 호환 GPU가 필요합니다. TechPowerUp GPU Database에서 GPU를 검색한 뒤 Graphics Features 항목으로 확인할 수 있습니다.


주요 GPU 제조사 3곳 모두 같은 개념의 자체 업스케일링 기술을 제공합니다:

  • DLSS: Nvidia 기술로, 기능이 가장 발전되어 있지만 RTX GPU에서만 사용할 수 있습니다.
  • FSR: AMD 기술로 FSR 3.1까지는 GPU 제한이 적지만 FSR 4는 RDNA 3/4 GPU만 지원합니다.
  • XeSS: Intel 기술로 여러 GPU에서 사용할 수 있지만 Intel Arc GPU에 더 최적화되어 있고 지원 범위도 상대적으로 좁습니다.

아래에 게임 해상도를 입력하고 Apply를 누르세요. 표의 색상은 각 업스케일러 preset이 얼마나 적합한지 보여줍니다. 초록색은 안정적이고 정확한 이미지를 재구성할 충분한 픽셀이 있다는 뜻입니다. 주황색과 빨간색은 성능이 최우선일 때만 고려하세요. 특히 DLSS 4는 화면을 아주 가까이 들여다보지 않는다면 낮은 입력 해상도에서도 비교적 잘 작동할 수 있습니다.

Skyrim과 Fallout 4처럼 업스케일링 통합이 잘 되어 있는 게임에서는 업스케일링을 사용하는 편이 대체로 유리합니다. 기존 AA, 특히 TAA와 비교하면 선명도, 미세 디테일 표현, 이미지 해상감이 크게 좋아지고 Native 모드가 아니라면 성능도 향상됩니다.
