Mod Organizer 2

Mod Organizer 2란?

Mod Organizer 2(MO2)는 Bethesda 게임에 주로 사용하는 오픈 소스 모드 관리자입니다. 주요 특징은 다음과 같습니다:

  • Virtual Filesystem (USVFS): MO2는 모드를 게임 폴더에 직접 설치하지 않고 게임이 읽을 가상 파일 시스템을 만듭니다. 덕분에 다음이 가능합니다:
    • 모드를 안전하게 설치하고 제거할 수 있습니다.
    • 언제든 모드 설치 순서를 바꿀 수 있습니다.
    • 서로 다른 모드 구성을 가진 여러 프로필을 만들 수 있습니다.
    • 원본 게임 파일을 깨끗하게 유지할 수 있습니다.
    USVFS의 단점은 다음과 같습니다:
    • MO2로 설치한 모드는 MO2를 통해 실행한 프로그램에서만 "보입니다".
    • 일부 프로그램은 MO2의 가상 파일 시스템에서 제대로 작동하지 않을 수 있습니다.
    • BSA/BA2로 묶이지 않은 loose 파일이 매우 많으면 USVFS로 인한 성능 오버헤드가 생길 수 있습니다.
    • USVFS는 NVSE 플러그인이나 ReShade와 비슷하게 게임에 "hooking"하는 방식으로 작동합니다. 메모리에 개입하는 특성 때문에 일부 백신이 위험 동작으로 판단할 수 있습니다.
  • Profile System: 서로 다른 모드 구성, 세이브, 설정을 가진 여러 프로필을 만들 수 있습니다.
  • Two pane interface: 왼쪽에는 모드 목록, 오른쪽에는 플러그인 목록이 표시됩니다. 충돌 해결과 모드 관리가 편리합니다.
  • Portability: USVFS 덕분에 "portable" 모드를 사용할 수 있어, 최소한의 재설정만으로 MO2 폴더 전체를 다른 위치로 옮길 수 있습니다.
  • Modding Community Integration: MO2는 Nexus Mods를 기본 지원하므로 Nexus에서 모드를 직접 다운로드할 수 있습니다.
    또한 플러그인 시스템을 통해 사용자 정의 플러그인으로 기능을 확장할 수 있습니다.

    Mod Organizer 2는 Nexus의 Collections 기능을 지원하지 않습니다. 따라서 모드는 하나씩 다운로드해야 합니다.
    하지만 가이드에서 필요한 모드의 직접 링크를 제공하므로 큰 문제는 아닙니다. 또한 많은 Collections는 선별 품질이 낮습니다.

    가장 가까운 대안은 커뮤니티 제작 모드리스트 설치기인 Wabbajack입니다. 전체 모드리스트를 자동으로 설치할 수 있고, 제작 진입 장벽이 더 높아 Collections보다 품질이 높은 편입니다.

    공식 The Midnight Ride Wabbajack 리스트 설치 방법은 여기에서 확인할 수 있습니다.

왜 Mod Organizer 2를 사용하나요?

Mod Organizer 2는 사용이 비교적 쉽고 게임 폴더를 깨끗하게 유지할 수 있어 원본 가이드에서 채택한 모드 관리자입니다. 충돌 해결과 모드 관리가 쉽고, 실수도 간단히 고칠 수 있습니다. 설치 순서가 잘못됐다면 올바른 위치로 끌어다 놓으면 됩니다.

Vortex와 달리 MO2는 모딩에서 중요한 부분을 사용자에게 숨기지 않아 무엇이 왜 일어나는지 파악하기 쉽습니다. 처음에는 다소 복잡해 보일 수 있습니다.

물론 MO2도 완벽하지 않고 자체적인 문제와 제한이 있지만, 이 가이드에서는 가장 적합한 도구로 판단합니다.

설치

Mod Organizer 2 설치

  1. Mod Organizer 2를 다운로드합니다.
  2. 다운로드가 끝나면 설치 프로그램을 실행합니다.
  3. 라이선스에 동의하고 Next를 누릅니다.
  4. 설치 위치를 묻는 화면에서 MO2를 The Midnight Ride로 바꾸고 Next를 누릅니다.

    Mod Organizer 2를 다른 위치에 설치하려면 Browse를 눌러 원하는 폴더를 선택합니다.

    설치 폴더는 Program Files x86 같은 Windows 기본 폴더와 게임의 Root 폴더 밖에 있어야 합니다.

    OneDrive 같은 클라우드 서비스를 사용한다면 문제나 성능 저하가 생길 수 있으므로 Desktop 또는 Documents에 MO2를 두지 않는 것을 권장합니다.

  5. 설치 구성 요소 페이지에서는 기본값을 그대로 사용합니다.
  6. Start Menu 폴더를 묻는 화면에서 Mod Organizer를 The Midnight Ride로 바꾸고 Next를 누릅니다.
  7. Desktop 바로가기는 만들지 않습니다. 나중에 별도로 만들 예정입니다.
  8. 마지막 페이지에서 Install을 누릅니다.
  9. 설치가 끝나면 Launch Mod Organizer가 체크되어 있는지 확인하고 Finish를 누릅니다.

MO2가 실행되지 않으면 FAQ의 이 해결 절차를 확인하세요.

초기 설정

Mod Organizer 2 설정

  1. 인스턴스 생성 페이지에서 Create a portable instance를 선택하고 Next를 누릅니다.
  2. Fallout 4를 선택하고 Next를 누릅니다.
  3. 게임을 구입한 스토어를 선택하고 Next를 누릅니다.
  4. 프로필 설정 화면에서는 모든 옵션을 활성화하고 Next를 누릅니다.
  5. 파일 경로는 default location을 그대로 사용합니다.
  6. 다음 페이지에서 Connect to Nexus를 누릅니다.
    1. MO2가 브라우저를 열고 연결 authorize를 요청합니다.
    2. 승인을 마치면 브라우저 페이지를 닫고 MO2에서 Next를 누릅니다.

MO2가 설치된 SSD/HDD의 여유 공간이 부족하다면 Show advanced options를 체크하고 Downloads 경로를 여유 공간이 많은 다른 드라이브로 바꿀 수 있습니다.
다운로드 파일 위치는 게임 성능에 영향을 주지 않으며, 모드 설치가 끝나면 다운로드 파일을 삭제해도 됩니다.

  1. 마지막 페이지에서 Finish를 선택합니다.
  2. Show tutorial? 팝업이 나오면 No를 선택합니다.
  3. Register? 팝업이 나오면 Yes를 선택합니다.
  4. INI file is read-only 팝업이 나오면 아래 드롭다운에서 Remember my choice를 선택한 뒤 Clear the read-only flag를 누릅니다.

게임 설정

이 단계에서는 Bethini Pie를 설치하고 실행합니다. 사용하기 쉬운 화면에서 최적화 preset과 세부 옵션을 설정할 수 있습니다.

  1. Bethini Pie를 다운로드합니다.
  2. 압축 파일을 Windows 기본 폴더 밖에 풉니다. 예: C:\Modding Tools
  3. MO2 오른쪽 패널에서 Run 버튼 옆 drop-down을 클릭합니다.
  4. 왼쪽 위의 <Edit...>를 누른 뒤 + 버튼 → Add from file을 선택합니다.
  5. 파일 선택 창에서 Bethini Pie 설치 위치로 이동해 Bethini.exe를 선택합니다.
  6. 오른쪽 아래의 Apply를 누른 뒤 OK를 누릅니다.
  7. 드롭다운에서 Bethini를 선택해 실행합니다.
  8. Fallout 4를 클릭한 뒤 Select Game을 누릅니다.
  9. Setup 창이 뜨면 OK를 누릅니다. MO2의 VFS가 리디렉션을 처리하므로 INI 경로를 MO2 프로필 폴더로 따로 바꿀 필요는 없습니다.
  10. 다음 설정을 적용합니다:
    1. 하드웨어에 맞는 Bethini preset을 선택합니다. 대부분의 시스템에는 High preset을 권장합니다.
    2. Recommended Tweaks를 적용합니다.
    3. Display Mode를 Borderless Windowed로 설정합니다.
    4. 게임에서 사용할 resolution을 선택합니다.
    5. Bethini Pie와 Steam 모두에서 Text Language가 English로 설정되어 있는지 확인합니다. 원본 가이드는 다른 게임 언어를 지원하지 않습니다.
    6. 나머지 설정은 취향에 맞게 조정합니다.

    Weapon debris는 기본적으로 꺼져 있습니다. Nvidia 그래픽카드 전용 기능이며 16 시리즈 이후 GPU에서는 충돌할 수 있습니다. 해당 충돌 수정은 뒤에서 설치합니다.

    1. 왼쪽 위에서 File → Save를 누르고 확인 창을 처리한 뒤 Bethini Pie를 종료합니다.

모드 설치 방법

Nexus와 MO2 사용 방법

가이드에서 모드 설치 파일은 Main File - Example 1.5처럼 표시합니다. 앞부분은 Nexus의 파일 분류, 뒷부분은 실제 파일 이름을 뜻합니다.

중요:
별도 지시가 없다면 항상 Mod Manager Download를 사용합니다.



모드 관리자를 통한 기본 설치 절차:
  1. 지정된 파일을 다운로드합니다.
  2. MO2 오른쪽의 실행 파일 선택기 아래에서 Downloads 탭을 엽니다.
  3. 모드를 더블클릭해 설치합니다.
  4. 왼쪽 패널에서 모드 체크박스를 켜 활성화합니다.

모드 관리자를 통한 다운로드를 사용할 수 없다면 다음과 같이 진행합니다:
  1. 해당 사이트의 Manual Download 버튼(또는 수동 다운로드 버튼)을 클릭합니다.
  2. 다운로드가 끝나면 MO2 상단의 버튼을 클릭합니다.
  3. 새 창에서 다운로드한 파일 위치로 이동해 파일을 더블클릭합니다.
  4. Mod Manager Download로 받은 모드와 같은 방식으로 설치를 마칩니다.

모드를 설치할 때 MO2가 다음 선택지를 표시할 수 있습니다:
  • Rename: 이미 설치된 모드와 같은 이름의 파일을 설치할 때 나타납니다. 예를 들어 모드 작동에 필요한 추가 파일이라면 이름 드롭다운이나 직접 입력으로 용도에 맞게 이름을 바꿉니다.
  • 기존 모드를 새 버전으로 업데이트할 때는 Replace를 선택합니다. 이전 버전의 파일을 모두 삭제하고 새 버전 파일로 교체합니다.
  • Merge는 해당 모드가 더 이상 업데이트되지 않는 것이 확실하거나 hotfix가 별도 파일로 올라온 경우에만 사용합니다. 가능한 한 모듈성을 유지하기 위해 사용을 피하세요.
