개요

LOD 이해하기

LOD는 Level Of Detail의 약자로, 멀리 있는 오브젝트를 단순화된 mesh와 texture로 표시해 성능을 확보하는 시스템입니다. Bethesda 게임에서 LOD는 주로 멀리 있는 지형의 전체 "덩어리"를 표현하는 Cell LOD를 뜻합니다.

Cell LOD는 세부 거리에 따라 연속적으로 바뀌는 방식이 아니라 해당 Cell이 로드됐는지 여부에 따라 전환됩니다. LOD Block distance 설정은 LOD가 시작되는 지점이 아니라 LOD 자체의 최대 표시 거리를 조절합니다.
따라서 이 설정을 바꾸더라도 LOD가 실제 오브젝트로 전환되는 pop-in 지점은 같은 거리에서 보입니다.

Cell LOD는 다음 주요 범주로 나뉩니다:

  1. Object LOD - 건물, 바위 등 정적 오브젝트의 단순화된 버전입니다. 품질 단계가 하나뿐이라 비교적 빠르게 생성됩니다.
  2. Terrain LOD - Cell 묶음의 지형을 표현하며 거리에 따라 여러 품질 단계(LOD4 4x4, LOD8 8x8 등)를 사용합니다. 구조가 복잡해 생성 시간이 가장 오래 걸립니다.

    3. Fallout 4에서는 Tree LOD를 따로 사용하지 않으며 모든 나무가 Object LOD에 포함됩니다.

왜 커스텀 LOD를 생성하나요?

바닐라 게임의 LOD는 미리 생성된 고정 데이터라 모드가 지형이나 오브젝트를 변경해도 그 내용을 반영하지 못합니다. 커스텀 LOD를 생성하면 현재 모드 구성에 맞는 mesh를 만들 수 있으며 다음과 같은 이점이 있습니다:

  • 가까운 오브젝트와 먼 오브젝트 사이의 시각적 일관성이 좋아집니다.
  • 멀리서 보이는 오브젝트 수가 늘어납니다.
  • 설치한 texture 모드와 어울리는 LOD texture를 사용할 수 있습니다.
  • 저해상도 바닐라 LOD보다 품질이 좋아집니다.
  • Cell 전환 시 오브젝트가 갑자기 나타나던 빈 공간을 줄일 수 있습니다.

The Midnight Ride는 TMR Extended까지 포함해도 Terrain LOD 재생성이 필수는 아닙니다. 다만 사용자 정의 모드 목록까지 대응할 수 있도록 이 가이드에서는 Object LOD와 Terrain LOD 생성 방법을 모두 설명합니다.

커스텀 LOD는 시각 품질을 크게 개선하지만 약간의 성능 비용이 있습니다. 대부분의 현대적인 시스템에서는 이 정도의 비용을 감수할 만한 편입니다.

Pre-Generated LOD

Texture나 게임 월드에 별도 변경을 하지 않은 TMRE 모드리스트를 사용한다면 이 파일로 수동 LOD 생성을 건너뛸 수 있습니다. Object LOD와 Terrain LOD가 모두 포함되어 있으며 Force LOD8을 활성화해 생성된 파일입니다.

일반 모드처럼 MO2에 설치한 뒤 앞에서 설치한 LOD 리소스 아래에 배치합니다. 앞의 리소스는 여전히 필요합니다. 마지막으로 다음 플러그인이 로드 오더에서 활성화되어 있는지 확인합니다:
  • FOLIP - Master.esm (ESM 중 가장 마지막)
  • FOLIP - Patch.esp (로드 순서 맨 아래)

LOD 생성

FOLIP Patch

  1. ModdingLinked의 설정 안내에 따라 xEdit를 설정합니다.
  2. 아무 플러그인이나 불러온 상태로 xEdit를 실행한 뒤 Settings에서 Simple Records를 비활성화합니다.
  3. FOLIP xEdit Scripts를 다운로드하고 압축 파일의 내용을 xEdit의 Edit Scripts 폴더에 넣습니다.
  4. xEdit를 다시 실행하고 모든 플러그인을 불러옵니다.
  5. 로드가 끝나면 아무 플러그인이나 우클릭하고 Apply Script...를 선택한 뒤 FOLIP을 선택하고 OK를 누릅니다.
  6. 원한다면 약간의 성능 비용을 감수하고 더 나은 비주얼을 위해 Force LOD8을 활성화할 수 있습니다.
  7. Start를 클릭합니다.
  8. 완료되면 "Patch generated successfully!" 메시지가 표시됩니다. OK를 누릅니다.
  9. xEdit를 종료하고 저장 여부를 묻는 창이 나오면 플러그인을 저장합니다.
  10. .zip 출력 파일이 있는 Explorer 창이 열립니다. 해당 파일을 MO2 모드 목록의 LOD 구분선 맨 아래로 끌어다 놓아 설치합니다.
  11. 출력 파일을 설치한 뒤 다음 플러그인이 로드 오더에서 활성화되어 있는지 확인합니다:
    • FOLIP - Master.esm (ESM 중 가장 마지막)
    • FOLIP - Patch.esp (로드 순서 맨 아래)

TexGen

  1. 최신 DynDOLOD 3 Alpha를 다운로드합니다.
  2. 다운로드가 끝나면 압축을 원하는 위치에 풉니다. UAC 보호 폴더나 게임 폴더는 사용하지 마세요.
  3. MO2 상단의 버튼을 클릭해 Executables 메뉴를 엽니다.
  4. 창 위쪽의 +를 클릭한 뒤 Add from file...을 선택합니다.
  5. 팝업에서 TexGen 설치 위치로 이동해 TexGenx64.exe를 선택합니다.
  6. 오른쪽 패널의 Arguments에 -FO4를 입력합니다.
  7. MO2 오른쪽 위 Executables 드롭다운에서 TexGen을 선택하고 Run을 클릭합니다.
  8. 프로그램이 로드되면 Base Size를 256 (1440p)으로 설정합니다. Object LOD atlas 한계를 넘을 때 발생하는 게임 엔진의 mipmap 버그 때문에 더 높은 해상도는 지원하지 않습니다.
  9. Start를 클릭합니다.
  10. 완료되면 "TexGen completed successfully" 메시지가 표시됩니다. Zip and Exit를 클릭합니다.
  11. MO2 상단의 버튼을 눌러 TexGen 출력 파일을 설치합니다.
  12. 새 창에서 2단계에서 설치한 DynDOLOD 폴더로 이동한 뒤 TexGen_Output.zip을 더블클릭해 설치합니다.

xLODGen

xLODGen은 게임용 LOD mesh를 생성하는 xEdit 기반 도구입니다. xEdit와 마찬가지로 하나의 실행 파일에 인자를 추가해 대상 게임에 맞게 실행합니다.

  1. 최신 xLODGen을 여기에서 다운로드합니다.
  2. 다운로드가 끝나면 Windows 기본 폴더 밖의 원하는 위치에 압축을 풉니다.
  3. MO2 상단의 버튼을 클릭해 Executables 메뉴를 엽니다.
  4. 창 위쪽의 +를 클릭한 뒤 Add from file...을 선택합니다.
  5. 팝업에서 xLODGen 설치 위치로 이동해 xLODGenx64.exe를 선택합니다.
  6. 오른쪽 패널의 Arguments에 -FO4 -O:"C:\Output"을 입력합니다.

    7. 이 인자는 LOD 출력 파일을 Windows가 설치된 C 드라이브의 Output 폴더로 보냅니다.
    원한다면 출력 경로를 다른 위치로 바꿀 수 있습니다. UAC 보호 폴더나 게임 폴더는 사용하지 마세요.

    LOD를 생성하기 전에 출력 폴더가 비어 있는지 확인합니다.

  7. MO2 오른쪽 위 Executables 드롭다운에서 xLODGen을 선택하고 Run을 클릭합니다.

    9. DLC03VRWorldspace에서는 LOD가 보이지 않으므로 해당 Worldspace의 LOD를 생성하는 것은 시간과 저장 공간만 낭비합니다.

    Terrain LOD 생성 방법 (선택 사항이지만 권장)

    Terrain LOD 생성은 CPU 부하가 매우 높으며, 설정과 CPU의 멀티스레드 성능에 따라 오래 걸릴 수 있습니다.

    Landscape 또는 landscape texture를 수정하는 모드를 사용한다면 필요합니다. 그런 모드가 없더라도 시각적 개선 폭은 큰 편입니다.

    1. 오른쪽 패널에서 Terrain LOD를 체크합니다.
    2. Landscape LOD는 거리에 따라 4개 단계로 나뉩니다. LOD4가 가장 가까운 거리, LOD32가 가장 먼 거리입니다.

    설정 설명

    오브젝트

    • Atlas size: atlas는 Object LOD mesh에 사용하는 모든 texture를 모아 둔 이미지입니다. 크기를 늘리면 새 리소스의 texture를 더 많이 담거나 더 높은 해상도로 넣을 수 있습니다.
      도구는 실제로 필요한 크기만큼만 atlas를 생성합니다. 예를 들어 필요한 크기가 1024x512라면 최종 atlas도 그 크기가 되며, 여기서 지정하는 값은 단지 허용되는 최대 크기입니다.
    • Max texture size: 이 값보다 큰 Object texture는 atlas에 포함되지 않습니다. 1024면 충분합니다.

    지형

    • Protect borders: Cell 경계에서 지형이 부자연스럽게 끊기거나 내려앉아 보이는 현상을 방지합니다.
    • Size: 대부분의 경우, 특히 TMR 같은 구성에서는 LOD4에 512, 이후 단계에 256이면 충분합니다. 고해상도 화면이나 지형 retexture를 사용한다면 더 높은 값이 유리할 수 있습니다. 다만 이 값은 생성 시간과 출력 파일 크기를 크게 늘릴 수 있습니다.
    • Bake normal-maps: 실제 지형의 normal map과 비슷하게 보이도록 Terrain LOD texture에 표면 굴곡 정보를 반영합니다.
    • Mipmap: 약간의 VRAM과 저장 공간을 사용하는 대신 texture의 pixel crawling artifact를 줄입니다.
    • Quality: LOD geometry의 세부 정도를 조절합니다. 값이 낮을수록 mesh의 triangle 수가 많아져 더 세밀하지만 약간의 성능 비용이 있습니다.
    • Optimize Unseen: 지정한 높이 아래 geometry의 triangle 수를 줄여 물속처럼 보이지 않는 영역을 최적화합니다.
  9. Generate를 클릭합니다.
  10. 완료되면 로그가 멈추고 마지막에 "LOD generation done" 메시지가 표시됩니다. 이제 xLODGen을 종료합니다.

LOD 설치

  1. MO2 상단의 모드 개수 표시 옆에 있는 작은 wrench 아이콘을 클릭한 뒤 Create empty mod를 선택합니다.
  2. 모드 이름을 FO4LODGen Output으로 지정합니다.
  3. LOD 파일이 생성된 위치로 이동해 textures와 meshes 폴더를 모두 선택합니다.
  4. 두 폴더를 방금 만든 FO4LODGen Output 모드 폴더로 잘라내어 옮깁니다. 모드를 우클릭하고 Open in Explorer를 선택하면 폴더를 열 수 있습니다.
  5. MO2에서 메뉴가 열려 있지 않은 상태로 F5를 누른 뒤 새 모드의 체크박스를 켜 활성화합니다.
