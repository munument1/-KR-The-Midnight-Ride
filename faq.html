일반

요구 사항과 지원하는 게임 버전은?

소개 페이지의 요구 사항을 확인하세요.

기존 세이브를 사용할 수 있나요?

짧게 답하면 안 됩니다.

기존 Fallout 4 세이브로 The Midnight Ride를 플레이하면 안 됩니다. 세이브 자체가 로드되더라도 변경 사항이 많아 정상 작동을 보장할 수 없습니다. 기존 세이브를 그대로 사용하는 구성은 원작 지원 대상도 아닙니다.

Linux를 지원하나요?

Linux 지원은 계획되어 있지만 가까운 시일 내에는 아닙니다. 현재는 원작 Discord server의 전용 채널에서 제한적으로 지원합니다.

Fluorine과 Amethyst 같은 프로젝트 덕분에 현재도 비교적 잘 작동하는 편입니다. 기본적인 Linux 사용법에 익숙하다면 별도의 상세 지침 없이도 진행할 수 있을 정도로 작업 흐름이 정리되어 있습니다.

비정품 게임도 작동하나요?

비정품 게임은 어떤 형태로도 지원하지 않습니다. 비정품 사용이 확인되거나 관련 대화를 할 경우 ModdingLinked Discord server에서 차단될 수 있습니다.

Long Loading Times Fix가 가이드에 없는 이유는?

Long Loading Times Fix는 자체적인 문제가 있으며, 가이드대로 설정한 High FPS Physics Fix보다 성능도 좋지 않습니다. 관련 비교는 benchmark 결과에서 확인할 수 있습니다.

대형 비주얼 모드가 많이 없는 이유는?

비주얼 모드를 얼마나 추가할 수 있는지는 하드웨어, 특히 VRAM에 크게 좌우됩니다. 대형 비주얼 모드를 기본 구성에 포함하면 가이드의 요구 사양이 지나치게 올라가 vanilla+라고 부르기 어려워집니다. 또한 많은 비주얼 모드는 loose file 형태로 게임 에셋을 교체해 성능에 부담을 줄 수 있습니다. 제대로 된 대규모 비주얼 구성을 만들려면 파일을 archive로 패킹하는 방법도 알아야 합니다.

세이브 파일은 어디에 저장되나요?

MO2를 통해 게임을 실행하면 세이브 파일이 일반적인 Documents 폴더에 나타나지 않습니다. 이 가이드와 Wabbajack은 세이브를 해당 인스턴스의 프로필 폴더로 보내는 profile-specific saves 기능을 사용합니다. MO2 오른쪽 패널의 Saves 탭에서 세이브를 바로 확인할 수 있습니다.

바닐라 세이브나 다른 모드 구성의 세이브를 재사용하지 마세요. 정상적인 플레이를 위해 새 캐릭터가 필요합니다.

문제 해결

아래 방법으로 해결되지 않는다면 원작 ModdingLinked Discord에서 지원을 요청할 수 있습니다.

게임이 충돌하거나 실행해도 아무 반응이 없습니다

원인은 여러 가지일 수 있습니다:

  • 이 단계에 따라 최신 VC++ Redistributables가 설치되어 있는지 확인합니다.
  • 게임의 Data 폴더에 호환되지 않는 모드 파일이 남아 있을 수 있습니다. 그래서 클린 설치가 필요합니다.
  • 타사 백신을 사용한다면 Mod Organizer 2 폴더를 예외로 추가합니다. 그래도 해결되지 않으면 타사 백신을 완전히 끄고 Windows Defender만 사용해 보세요. Defender는 예외 설정이 되어 있다면 정상 작동하는 편입니다.
  • PRP에서 필요한 두 파일을 모두 설치했는지 확인합니다.
  • Missing masters 여부를 확인합니다. Mod Organizer 2 오른쪽 위의 큰 빨간 삼각형 아이콘을 확인하세요:
    • TMR에 포함된 모드가 빠졌다면 해당 모드를 설치하거나, 그 모드를 요구하는 패치를 제거합니다. 예를 들어 TMR Extended에서 사용하지 않는 모드의 패치를 실수로 설치했을 수 있습니다.
    • 바닐라 Creation Club 콘텐츠가 빠졌다면 Steam에서 게임 파일 무결성 검사를 실행합니다..
  • 완제품 PC나 노트북에 기본 설치된 관리 프로그램(예: HP OMEN 시스템의 OMEN Gaming Hub)은 문제를 일으키는 경우가 있으므로 제거하거나 일시적으로 종료해 보세요.
  • 그래픽 드라이버를 최신 버전으로 업데이트합니다: Nvidia, AMD, Intel.

모드 목록과 로드 오더를 어떻게 내보내나요?

지원하는 모드 관리자는 MO2뿐이므로 다른 관리자의 방법은 제공하지 않습니다:

  1. MO2 상단의 폴더 목록 버튼을 클릭합니다.
  2. Open Profile Folder를 클릭합니다.
  3. 모드 목록은 modlist.txt에 저장됩니다. 역순으로 기록되지만 텍스트 편집기로 쉽게 뒤집을 수 있습니다. 로드 오더는 loadorder.txt에 저장됩니다.

Creation Kit이 모드를 인식하지 못합니다

MO2에서는 Creation Kit을 포함한 대부분의 도구를 MO2의 Executables 목록을 통해 실행해야 합니다. 그래야 프로그램이 VFS와 함께 실행되어 설치한 모드를 모두 볼 수 있습니다.

MO2 인스턴스를 만들 때 Fallout 4가 보이지 않습니다

게임을 한 번 실행한 뒤 MO2 설치 프로그램을 다시 시작해 시도합니다.

INI 파일을 초기화하는 방법

  1. MO2 상단의 버튼을 클릭하고 INI Editor를 선택합니다.
  2. Fallout4.ini와 Fallout4Prefs.ini의 내용을 모두 지우고 두 파일을 저장합니다.
  3. MO2를 통해 게임 런처를 실행하면 새 INI 파일이 생성됩니다.

가이드를 따랐다면 profile-specific INI를 사용하므로 이 작업도 MO2 안에서 진행해야 합니다.

게임 파일 무결성 검사를 해도 되나요?

네. TMR은 원본 게임 파일을 직접 수정하지 않으므로 영향을 받지 않습니다.

Application load 오류

  • 5:0000065434: Steam이 실행 중인지 확인합니다. 해결되지 않으면 Steam에서 게임을 직접 한 번 실행합니다. Steam이나 Mod Organizer 2를 재시작해야 할 수도 있습니다. 그래도 안 되면 Steam.exe의 복사본(바로가기가 아님)을 게임의 Root 폴더에 넣어 보세요.

MO2 왼쪽 패널에서 모드가 loose file을 덮어썼다고 표시됩니다

MO2 왼쪽 패널의 모드 순서가 가이드와 정확히 일치한다면 정상적이고 의도된 상태입니다.

게임 속도가 비정상적으로 빨라집니다

MO2에서 F4SE로 게임을 실행하고, 여기의 지시에 따라 High FPS Physics Fix를 설치하고 설정합니다.

Mod Organizer 2가 실행되지 않고 매번 dump 파일을 만듭니다

이 단계에 따라 최신 VC++ Redistributables가 설치되어 있는지 확인합니다.

모드가 MO2로 다운로드되지 않거나 Vortex로 다운로드됩니다

  1. MO2 상단의 버튼을 클릭해 Settings를 엽니다.
  2. Nexus 탭에서 Connect to Nexus를 선택합니다.
  3. MO2가 브라우저를 열고 연결 authorize를 요청합니다.
  4. 승인을 마치면 브라우저 탭과 MO2 Settings 창을 닫습니다.
  5. MO2가 restart하도록 허용합니다.

Wabbajack 설치 중 오류가 발생합니다

  • GOG 버전을 사용 중인지 확인합니다. GOG판은 TMR 가이드와 Wabbajack 모두 지원하지 않습니다.
  • 모든 DLC를 포함한 클린 설치 상태인지 확인합니다.
  • Steam과 Bethini Pie에서 게임 언어를 모두 English로 설정합니다. 다른 게임 언어는 지원하지 않습니다.
  • 그래도 해결되지 않으면 Wabbajack 오른쪽 위 Settings의 톱니바퀴를 클릭하고 Nexus에서 로그아웃한 뒤 다시 로그인하여 설치를 처음부터 다시 실행합니다.

새 게임 로딩에서 멈춥니다

High FPS Physics Fix의 설정 방법에 따라 OneThreadWhileLoading을 비활성화합니다. 외부 FPS 제한기가 적용되어 있지 않은지도 확인하세요.

음성이 나오지 않거나 잘못된 언어의 텍스트가 표시됩니다

Bethini Pie 항목 전체를 다시 확인하고, 특히 언어가 English로 설정되어 있는지 확인합니다.

문 상호작용 문구나 Location 이름이 English가 아닙니다

PRP의 Plugin 파일을 잘못 설치한 것입니다. 여기에서 English 버전을 설치합니다.

월드 일부가 보이지 않거나 깜빡입니다

Previs Repair Pack 항목대로 PRP Resources를 설치하고, 아직 적용하지 않았다면 가이드의 Load Order를 적용합니다.

새 게임을 시작하면 검은 화면이 나옵니다

Bethini Pie와 Steam 모두에서 Text Language가 English로 설정되어 있는지 확인합니다. 다른 게임 언어는 지원하지 않습니다.

"Signature scan failed" 오류

Unlimited Survival Mode - F4SE의 achievements patch를 설치 단계의 지시에 따라 비활성화합니다.

설정

FOV는 어떻게 바꾸나요?

Bethini Pie를 사용합니다.

LOD를 다시 생성해야 하나요?

새 LOD 생성은 필수가 아닙니다. 다만 멀리 있는 Cell을 모드로 변경된 가까운 지역의 모습과 맞춰 부자연스러운 차이를 줄이고 디테일도 크게 개선할 수 있어 대체로 권장합니다.

전체 생성 방법은 LOD 가이드에서 확인할 수 있습니다.

필요한 INI 변경은 무엇인가요?

성능에 필요한 INI 변경은 Bethini Pie에서 이미 적용됩니다.
추가로 바꾸고 싶은 설정이 있다면 MO2 상단의 버튼에서 INI Editor를 열어 FalloutCustom.ini에 추가합니다.

가이드에서 DLC 플러그인을 clean하지 않는 이유는?

Fallout 4에서 플러그인 cleaning은 이점도 불이익도 없습니다. 굳이 시간을 들일 이유가 없습니다.

Ultrawide를 지원하나요?

Ultra Wide Interface (21x9)를 설치합니다.

High Resolution Texture Pack DLC를 비활성화해야 하는 이유는?

High Resolution Texture Pack은 시각적 개선이 매우 작은 반면 성능은 크게 떨어질 수 있습니다. 비용 대비 이점이 너무 적습니다.
