성능 설정 안내

FPS 제한은 전체적인 안정성에 매우 중요합니다. 특히 프레임 페이싱을 일정하게 만들어 체감 부드러움에 큰 영향을 줍니다.

고급 FPS 제한기는 지연 시간을 줄이거나 CPU 전력 소모를 낮추는 데도 도움이 됩니다. 다만 두 효과를 동시에 크게 얻기는 어렵습니다.

FPS 제한기는 실제로 안정적으로 유지할 수 있는 프레임레이트에 맞춰야 의미가 있습니다. 이렇게 하면 GPU 사용률이 계속 100%에 붙는 것을 막아 지연 시간을 더 줄이고, 전력 소모도 상당히 낮출 수 있습니다.

설정

  1. V-Sync[1]가 활성화되어 있는지 확인합니다. Bethini Pie에서 설정할 수 있으며, 그래픽 드라이버 설정이 이를 덮어쓰지 않도록 합니다[2].
  2. 모니터가 지원한다면 Variable Refresh Rate(VRR)[3]를 활성화합니다.

    3. VRR을 사용할 때 V-Sync를 끄지 마세요. VRR은 V-Sync가 활성화되어 있다고 가정합니다[4].

  3. Fallout 4에서는 특히 외부 FPS 제한기를 사용하지 마세요. 아래 단계에서 High FPS Physics Fix 자체 제한기를 설정합니다. Fallout 4는 로딩 속도가 프레임레이트와 연결되어 있어 외부 제한기로는 로딩 중 제한값을 동적으로 바꿀 수 없고, 그만큼 로딩 가속 효과를 놓치게 됩니다.

참고 설명

  1. V-Sync는 모니터의 VBLANK를 GPU 출력과 동기화해 화면 찢어짐을 방지합니다. 그 결과 프레임레이트가 모니터 주사율을 넘지 않게 됩니다.

    V-Sync가 제한기처럼 동작하기는 하지만 V-Sync 자체는 FPS 제한기가 아닙니다. 별도의 제한기 없이 V-Sync만 사용하면 입력 지연이 크게 늘 수 있습니다.

  2. 일반적으로 Nvidia Control Panel과 AMD Adrenalin 모두 기본 설정이면 충분합니다. 잘 모르겠다면 기본값으로 초기화하고, 기능을 정확히 이해하지 못한 설정은 바꾸지 마세요.
  3. Nvidia는 Nvidia Control Panel, AMD는 Adrenalin의 Display Settings에서 VRR을 활성화할 수 있습니다. 해당 설정이 없다면 디스플레이가 VRR을 지원하지 않거나 모니터 OSD에서 기능이 꺼져 있을 수 있습니다.

    Nvidia 사용자는 G-Sync를 Fullscreen으로 설정하고 Display Specific settings를 활성화해야 합니다. Windowed 옵션은 우회 방식이라 문제가 생길 수 있습니다.

    이 설정들의 이름은 실제 동작을 정확히 설명하지 않습니다. 표시 방식 자체를 직접 뜻하는 옵션은 아닙니다.

  4. 널리 퍼진 오해와 달리 VRR만으로 화면 찢어짐이 완전히 없어지지는 않습니다. 롤링 티어를 줄일 수는 있지만 효과는 디스플레이마다 다릅니다. 또한 지연 감소 효과는 프레임레이트가 모니터 주사율보다 낮을 때만 적용됩니다.

    프레임레이트가 주사율에 도달하면 VRR이 V-Sync 에뮬레이션을 사용합니다. 따라서 VRR 사용자는 순간적인 프레임 상승을 고려해 FPS 제한을 주사율보다 약간 낮게 설정해야 합니다.

이 부분은 원리를 설명하기 위한 내용입니다. 아래 계산기가 이 조건들을 모두 고려해 권장 값을 계산합니다.


High FPS Physics Fix

FPS 제한을 해제한 환경에서도 부드럽게 플레이할 수 있도록 하고, 끊김을 완화하며 로딩 시간을 크게 줄여주는 종합 수정 모드입니다.

설치 방법

  • Main Files - High FPS Physics Fix
    1. 모드를 설치한 뒤 MO2 왼쪽 패널에서 해당 모드를 더블클릭합니다.
    2. INI Files 탭에서 F4SE/Plugins/HighFPSPhysicsFix.ini를 엽니다.
    3. 다음 항목만 변경합니다:
      • DisableBlackLoadingScreens를 true로 설정합니다.
      • PostloadingMenuSpeed를 2.0으로 설정합니다.
      • OneThreadWhileLoading를 false로 설정합니다.
      • 아래 계산기로 권장 FPS 제한값을 구합니다. 정확한 모니터 주사율은 여기에서 확인할 수 있습니다.
      • InGameFPS와 PipBoyFPS를 위 계산기의 권장 값으로 설정합니다.
      • InGameFPS를 60보다 높게 설정했다면 다음 항목도 적용합니다:
        • DynamicUpdateBudget를 true로 설정합니다.
        • BudgetMaxFPS를 InGameFPS와 같은 값으로 설정합니다.
    4. 변경 사항을 저장합니다.
