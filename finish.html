확장 구성 마무리

로드 오더 적용

마지막 단계는 설치한 플러그인의 로드 오더를 적용하는 것입니다. 가이드에서 제공하는 미리 구성된 로드 오더 파일을 사용하면 충돌 관계를 고려한 올바른 순서로 모드를 불러올 수 있습니다.

  1. TMR Load Order를 여기에서 다운로드합니다.
  2. MO2 상단의 버튼을 클릭한 뒤 Open Profile folder를 선택합니다.
  3. loadorder.txt를 MO2 프로필 폴더로 옮깁니다. 기존 파일 덮어쓰기 여부를 묻는 창이 나오면 Yes를 누릅니다.
  4. MO2에서 메뉴가 열려 있지 않은 상태로 F5를 누릅니다.
  5. MO2 오른쪽 패널을 우클릭하고 Enable all을 선택합니다.

MO2 오른쪽 패널의 Plugins 탭에 표시되는 로드 오더가 방금 받은 loadorder.txt와 같아야 합니다. 설치하지 않은 모드의 플러그인은 없어도 되지만 남아 있는 플러그인의 순서는 파일과 일치해야 합니다.

다르다면 위쪽 Priority 열 머리글을 눌러 우선순위 기준으로 정렬했는지 확인하세요.

추가 지원이 필요하면 원작 Discord를 이용할 수 있습니다.

게임 실행

Mod Organizer 2의 작동 방식상 모드를 불러오려면 프로그램을 MO2를 통해 실행해야 합니다. 오른쪽 위 실행 프로그램 선택 메뉴에서 F4SE를 선택합니다.

편의를 위해 Run 버튼 바로 아래에서 바로가기를 만들어두면 게임을 할 때마다 MO2를 직접 열 필요가 없습니다.

MCM 설정

게임에 들어간 뒤 Mod Configuration 메뉴에서 각 모드 설정을 취향에 맞게 조정합니다.

이제 The Midnight Ride 전체 구성을 마쳤습니다. 게임을 시작해도 됩니다.
