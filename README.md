# The Midnight Ride 비공식 한국어 가이드

이 저장소는 [ModdingLinked의 The Midnight Ride](https://themidnightride.moddinglinked.com/)를 기반으로 한 **비공식 한국어 번역 프로젝트**입니다.

- 공식 ModdingLinked 배포판이나 공식 한국어판이 아닙니다.
- 설치 순서와 기술적 내용은 원본 가이드를 기준으로 유지합니다.
- 모드명, 프로그램명, 파일명, 경로, INI 키와 실제 UI 버튼명은 정확성을 위해 원문 표기를 우선합니다.
- 원본의 저작권 고지와 MIT 라이선스를 유지합니다.
- 공개 준비가 끝날 때까지 서비스 페이지에는 noindex, nofollow, noarchive가 적용됩니다.

## 원본

- 원본 가이드: https://themidnightride.moddinglinked.com/
- 원본 저장소: https://github.com/ModdingLinked/The-Midnight-Ride
- 원작자 후원: https://www.patreon.com/moddinglinked

> 원작자 후원 링크는 이 한국어 번역 프로젝트가 아니라 원작 ModdingLinked 제작자에게 연결됩니다.
